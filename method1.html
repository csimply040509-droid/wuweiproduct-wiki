方法论 01 · 五维产品分析法

词条页 · 五维产品分析知识站　|　← 返回首页

定义与核心价值

五维产品分析法是一种选品理解框架：面对任何一个要拍的产品，先按「痛点→人群→需求→环境→卖点」五个维度拆透，再决定拍什么、怎么拍。它的核心价值是把"拍什么"从拍脑袋变成可推导的流程，让选题从"拍好看"升级为"为转化服务"——你理解产品有多深，素材上限就有多高。

核心概念：五个维度

五维不是并列罗列，而是从痛点出发、落到卖点的推导链：

  • 痛点：用户不用/用不好的真实麻烦。最核心，先想这个——它决定钩子。
  • 特殊人群：谁最痛、最该被精准触达（母婴 / 健身 / 银发…）。吃的人、买的人、影响的人往往不是同一人。
  • 特殊需求：该人群在场景里要满足的具体诉求。往深挖一层：表层需求背后，用户真正想完成的"事"是什么？
  • 特殊环境：使用发生的典型时空（通勤 / 厨房 / 户外…），决定画面语境与产品约束。
  • 核心卖点：综合以上四点，产品凭什么赢——一句话打透，并翻成用户听得懂的利益。

核心模板：五步推导表

步骤问自己产出
1 痛点用户最烦的是什么？（看竞品差评、品类吐槽）痛点清单
2 人群谁最痛？食用者/购买者/影响者分别是谁？目标人群画像
3 需求表层需求背后要完成什么"事"？哪块没人满足？需求表述
4 环境在哪些场景用？每个场景有什么约束？场景×约束矩阵
5 卖点我的差异怎么解这题？凭什么赢？一句话卖点 + 3 条候选钩子
执行顺序口诀：痛点（骂什么）→ 人群（谁在骂）→ 需求（深层任务）→ 环境（在哪发生）→ 卖点（我怎么解）。

实施步骤（现场版）

  1. 开拆前先看竞品和差评：用户骂什么，痛点就在哪里；不要凭想象编痛点。
  2. 逐维填表，每维要证据：评论、竞品对比、配料表/参数，而不是"我觉得"。
  3. 卖点用一句话收口：写不出就是没想透，回去重拆。
  4. 产出 3 条候选钩子：直接作为脚本弹药进入下一环节。

应用案例：不二宝贝 · 牛肉海苔碎拌饭料

产品基线：96g/袋、独立小包，主打"三无标准"（无防腐剂/香精/增稠剂）的婴幼儿辅食；牛肉松 ≥40%；京东 2 袋 22 包约 ¥49.9。

  • 痛点：添加剂焦虑、饭渣宝宝不吃、肉泥没口感不锻炼咀嚼、海苔碎受潮/颗粒呛咳、外出喂养难。
  • 人群：核心 = 1-3 岁宝宝的妈妈（饭渣家庭、成分党、食安敏感）；次级 = 隔代祖辈、托班加餐、送礼。
  • 需求："省心搭子"（一袋解决调味+增香+营养）、"干净且好吃"兼得、自主进食锻炼精细动作。
  • 环境：居家正餐 / 亲子饭团手工 / 外出旅行 / 加餐干吃，附硬约束（防潮、低钠、控量）。
  • 卖点：「让宝宝主动干饭的无添加真肉松拌饭料」——真牛肉松 ≥40% + 低温慢煮保留肉纤维（区别于竞品海苔粉/调味粉）。

案例→素材的落地衔接：

五维产出素材动作
卖点 + 信任状主图白底 + 颗粒特写 + 尺寸参照；详情页放 SGS 检测背书
人群 + 痛点前 3 秒钩子："你家也是饭渣宝宝吗？" 直击宝妈焦虑
环境 + 需求分镜覆盖居家拌饭 / 外出便携 / 饭团手工三类场景

价值与局限

核心价值

  • 把"拍什么"从拍脑袋变成可推导的流程，素材命中率显著提升；
  • 五维产出（痛点→解法、场景→约束）可直接当脚本素材，省写稿时间；
  • 重复产品再来时，翻档案即可复用，不重做分析。

潜在局限

  • 五维需要证据支撑（评论、竞品、配料表），偷懒拍脑袋会退回"我觉得"；
  • 一版拆解≠永远正确，卖点会随市场变化，需在复盘中持续修订。
